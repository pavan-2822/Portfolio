06 Principles
P-01 Latency is a feature. A response that arrives late is a response that didn't happen. FP16, batching, and quantization are model decisions, not afterthoughts.
P-02 Every answer needs a receipt. A model shouldn't be trusted to remember a number it should be trusted to fetch one. Retrieval and deterministic tool calls exist so figures come from a source, not a guess.
P-03 Alert on burn, not thresholds. A page should mean the error budget is being spent not that a metric crossed an arbitrary line at an inconvenient hour.
P-04 Evaluation is the deliverable. A model or prompt change that hasn't been graded against a golden set isn't shipped, it's a guess. The eval gate is the product; the change is its payload.
